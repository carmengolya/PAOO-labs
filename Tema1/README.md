# Tema 1 — Bibliotecă statică C++

## Obiectiv

Se vor realiza două proiecte C++ independente, configurate cu ajutorul
fișierelor `CMakeLists.txt`. Primul proiect va furniza o bibliotecă statică,
iar cel de-al doilea proiect va utiliza funcționalitățile oferite de aceasta.

## Cerințe

- configurarea celor două proiecte C++ folosind fișierele `CMakeLists.txt`
  aferente;
- implementarea, în primul proiect, a unei biblioteci statice;
- expunerea funcționalităților bibliotecii printr-un fișier header cu extensia
  `.h`;
- utilizarea bibliotecii statice create în primul proiect de către cel de-al
  doilea proiect.

## Rezultatul așteptat

La final, al doilea proiect trebuie să poată fi compilat și rulat folosind
biblioteca statică generată de primul proiect.
